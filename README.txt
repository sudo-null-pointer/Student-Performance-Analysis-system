STUDENT PERFORMANCE ANALYSIS SYSTEM - How to run

Requirements : Python 3 (matplotlib is needed only for option 9)
Install      : pip install matplotlib

Run          : python student_performance.py
               (keep students.csv in the same folder)

Files
  student_performance.py   - complete source code
  students.csv             - student data (8 sample records)
  class_report_*.txt       - report created by menu option 8
  subject_average.png      - chart created by menu option 9
  Screenshots/             - important outputs of the program
  Student_Performance_Analysis_Project_Report.pdf - project report
  Student_Performance_Analysis_Presentation.pptx - presentation slides
  Team_Contribution_Details.txt
